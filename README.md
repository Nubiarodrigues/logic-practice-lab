# 💻 Branch de exercícios de lógica em java

Este repositório contém exercícios práticos de **lógica de programação** desenvolvidos em **Java**, com o objetivo de aprimorar raciocínio lógico e resolução de problemas de forma eficiente e rápida.

---

## 🗂️ Organização dos exercícios

Os exercícios estão organizados por **pacotes numerados**, no seguinte formato:

```
src/
├── exercise_1005/
│   └── exe_1005.java
├── exercise_1006/
│   └── exe_1006.java
├── exercise_1007/
│   └── exe_1007.java
└── ...
```


> 📌 Cada pacote contém **um exercício com sua própria classe `main`**, que pode ser executada individualmente.

---

## 🚀 Como executar os exercícios

1. Clone o repositório:
   ```bash
   git clone https://github.com/Nubiarodrigues/logic-exercises.git 
   ```

2. Abra o projeto na sua IDE preferida (recomendado: **IntelliJ IDEA**).

3. Navegue até o pacote desejado e execute a classe que contém o método `main`.

---

## 🎯 Objetivo

> Consolidar o raciocínio lógico e os fundamentos da linguagem Java através de exercícios simples, organizados e progressivos.

---

## 🛠️ Tecnologias utilizadas

- [Java JDK 17+](https://www.oracle.com/java/technologies/javase-downloads.html)  
- [IntelliJ IDEA](https://www.jetbrains.com/idea/)
